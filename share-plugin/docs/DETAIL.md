# 文件分享

给 DSH 的文件右键菜单加一条 **分享**：在手机上把文件直接交给系统分享面板，选微信、QQ、钉钉或邮箱发出去，不用先下载再找文件。

## 用法

1. 在 DSH Remote App 里打开任意会话，长按文件卡或文件路径。
2. 菜单末尾点「分享」。
3. App 从电脑取回文件（有进度），随后弹出系统分享面板；选微信即可转发给好友或文件传输助手。

## 说明与限制

- 只在**装了 DSH Remote 1.10 及以上**的 App 里显示；桌面浏览器没有这个桥，菜单保持原样。
- 首次分享同一个文件会先下载（走 `/__fs`，单个文件上限 32 MB），之后本机缓存直接复用。
- 分享的是文件的本地缓存副本；微信等应用是否能发送该类型，由对方决定。
- 需要 `dsh-file-share` 这个 bundle 保持启用。

## 安装与停用

- 这个 bundle 是用本地目录安装进 profile `desktop` 的，源目录就是当前仓库的 `share-plugin/`，
  安装后是**链接**而不是拷贝；移动或删除该目录会让插件失效，需要重新安装。
- 在 **Plugins** 里可以停用或移除；停用后文件右键菜单恢复原样，不影响 App 的其他功能。
- 升级 Web 端后如果菜单里没出现「分享」，刷新一次页面（手机 App 里重开也行），
  让 Client 模块重新加载。
